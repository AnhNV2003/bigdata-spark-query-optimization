# 5. Distributed Query Optimization on Columnar Storage

- Description: Analyze performance bottlenecks in Petabyte-scale queries and propose optimization strategies for distributed storage.
- Key Requirements:
  - Compare performance across formats (Parquet, ORC, Avro).
  - Optimize Partitioning and Bucketing to maximize data skipping.
  - Address Data Skew issues in large-scale distributed JOIN operations.
- Application Themes: Telecom Event Log Analysis or Large-scale GPS Trajectory Processing.
- Suggested Data Sources: NYC Taxi Trip Records or Criteo 1TB Click Logs.
